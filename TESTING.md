# Manual test cases

Run these on a real Android phone with Expo Go (`npx expo start`) or with an
installed APK.

## Before you start

1. Run `supabase/schema.sql` on the Supabase project (README section 1).
2. In Supabase → Authentication → Phone, add three **test phone numbers**:
   `919000000001=111111`, `919000000002=222222`, `919000000003=333333`.
3. Make `9000000001` the admin (run in the SQL Editor):
   ```sql
   insert into public.staff_invites (phone, full_name, role)
   values ('9000000001', 'Owner', 'admin');
   ```
4. Do **not** invite `9000000003` yet. It plays a stranger.

"Admin" means you are logged in as 9000000001. "Staff" means 9000000002
(you add it in test 4).
